# EduTrack Platform 🚀

A modern, full-stack educational management platform designed to streamline student tracking, group management, attendance, exams, and financial records for educational institutions and instructors.

---

## 🛠️ Tech Stack

### Backend (API)
* **Framework:** Laravel 11 (PHP)
* **Database:** MySQL
* **Authentication:** Laravel Sanctum

### Frontend (Client)
* **Library:** React.js (Vite)
* **Styling:** Modern CSS / Custom UI/UX
* **Data Visualization & Charts:** Recharts
* **HTTP Client:** Axios
