# 📚 نظام إدارة السنتر التعليمي (Center Management System)

نظام متكامل لإدارة الطلاب، المجموعات، الحضور والغياب، الامتحانات، والإدارة المالية (المقبوضات والمصروفات) مصمم خصيصاً لتسهيل إدارة السنتر بدقة وسهولة.

---

## 🚀 التقنيات المستخدمة (Tech Stack)
* **Backend:** Laravel (API RESTful)
* **Frontend:** React.js
* **Styling:** CSS / Modern UI

---

## 🌟 مميزات النظام الأساسية
1. **إدارة الطلاب:** إضافة وتعديل بيانات الطلاب، الصور الشخصية، والمجموعات.
2. **جدول متابعة الشهور (Checkboxes):** جدول تفاعلي لمتابعة سداد الطلاب للمصروفات شهرياً (من أكتوبر حتى يونيو) مع ربطه بقاعدة البيانات.
3. **قسم الحسابات والمقبوضات:** تسجيل دفعات الطلاب ومتابعة الإيرادات والمقبوضات أول بأول.
4. **قسم المصروفات:** تسجيل المصروفات المختلفة (إيجارات، طباعة، خدمات) وخصمها تلقائياً.
5. **التقرير المالي (الخزينة والصافي):** حساب إجمالي المقبوضات وإجمالي المصروفات وصافي المتبقي في الخزينة بدقة.

---
